# RabbitMQ UI Feature Matrix & Modernization Opportunities

This matrix maps every capability observed in the classic RabbitMQ management UI screenshots (`1.png` - `17.png`) directly to the corresponding HTTP API endpoints, operational parameters, and high-impact UX improvements for **RabbitDash**.

---

## Complete Feature Matrix

| Domain | Classic UI Feature | Screenshot Reference | Underlying HTTP API Endpoint | Form Inputs / Parameters / Actions | Modern UI ("RabbitDash") Redesign & Enhancement |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **Auth** | Login Screen | `login.png` | `/api/whoami` | Username input, Password input, Login button | Multi-cluster profile manager, server URI selector, OAuth2/OIDC SSO, connection latency test, offline demo mode. |
| **Global** | Auto-Refresh Polling | `1.png` - `17.png` | Client timer polling `/api/*` | Dropdown: [Off, 5s, 10s, 30s, 60s] | Combine polling with optional real-time WebSocket / SSE streaming; smooth animated chart transitions. |
| **Global** | Virtual Host Selector | `1.png` - `17.png` | `/api/vhosts` | Dropdown: `All` or specific vhost | Persistent searchable combobox with quick keyboard shortcut (`Ctrl+V` / `Cmd+V`); remembers favorite vhosts. |
| **Global** | Cluster & User Status | `1.png` - `17.png` | `/api/whoami`, `/api/overview` | Cluster name tag, User badge, Logout | Modern avatar badge with quick role indicator, multi-cluster environment switcher, Dark/Light mode toggle. |
| **Global** | Table Pagination & Filters | `2.png`, `3.png`, `5.png`, `7.png`, `8.png`, `10.png` | `/api/<entities>?page=1&page_size=100` | Page input, Filter string, `Regex ?` toggle, page size, Column visibility `+/-` | Instant client/server search-as-you-type, multi-column sorting, sticky headers, tag filters, column resizing & pinning. |
| **Overview** | Queued Messages Chart | `1.png` | `/api/overview` | Time window selector (last hour) | Multi-series time-series with zoom/pan, custom date ranges (15m, 1h, 6h, 24h, 7d), tooltip crosshairs, metric toggle. |

| **Queues** | Queue Detail | `17.png` | `/api/queues/<vhost>/<name>` | Queued messages & rates charts, node replica status, consumer capacity | Multi-metric dashboard, quorum replica health status, consumer saturation meter. |

| **Queues** | Inbound Bindings | `17.png` | `/api/queues/<vhost>/<name>/bindings` | Source exchange, Routing key, Arguments, Unbind, Add binding | Visual representation of upstream exchanges feeding this queue; 1-click navigation to source exchange. |
